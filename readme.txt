# موقع معرض الأعمال — GitHub Pages

## طريقة الرفع
1. فك ضغط الملف.
2. افتح مستودع GitHub الخاص بك أو أنشئ مستودعاً جديداً.
3. ارفع `index.html` إلى جذر المستودع (مو داخل مجلد فرعي).
4. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)` واحفظ.
5. افتح رابط GitHub Pages الذي يظهر لك.

## رمز الإدارة
الرمز الافتراضي: `Sino2026!`
غيّره داخل `index.html` وابحث عن:
`const ADMIN_PASSWORD = "Sino2026!";`

تفتح لوحة الإدارة من كلمة «إدارة» الصغيرة أسفل الصفحة.

## تنبيه مهم جداً
هذا إصدار تجريبي ثابت مناسب للعرض والتجربة:
- المشاريع وبيانات البراند تُحفظ في Local Storage في نفس المتصفح فقط.
- أي مشروع تضيفه من لوحة الإدارة لن يظهر تلقائياً عند زائر آخر أو على جهاز آخر.
- رمز المرور داخل ملف HTML ليس حماية أمنية حقيقية؛ يمكن لمن يعرف البرمجة استخراج الرمز من مصدر الصفحة.
- حتى تظهر المشاريع لجميع الزوار وتكون الإدارة محمية، يلزم ربط قاعدة بيانات وخدمة تسجيل دخول (مثل Appwrite أو Supabase) مع إعدادات آمنة.

لا تخزّن معلومات الزبائن أو أي بيانات حساسة في هذا الإصدار.
